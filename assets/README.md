# LoveMi 界面素材

三张角色图使用内置 imagegen，根据本次提供的 60% / 100% 卡片截图重建，保留透明背景。

| 文件 | 用途 |
| --- | --- |
| `lovemi-cat-wave.png` | 页面顶部的眨眼举爪猫咪 |
| `lovemi-cat-laptop.png` | 60% 阶段卡的笔记本猫咪 |
| `lovemi-cat-peek.png` | 100% 画像卡的趴边猫咪 |

生成提示要点：保留参考图的灰白毛绒 3D 猫咪、橙色耳内、金色瞳、金项圈与 M 吊坠；分别生成举粉爪、趴笔记本、双爪趴卡片边三种姿态。真实透明背景，无文字、无完整界面。

`paw.svg` 与进度条小猫为界面原生矢量装饰。`portrait-1.jpg` 至 `portrait-3.jpg` 是体验人物卡的示例头像，来自 Unsplash 的图片 `photo-1500648767791-00dcc994a43e`、`photo-1506794778202-cad84cf45f1d`、`photo-1535713875002-d1d0cf377fde`；只用于示例卡片，不代表这些照片中的人的身份或资料。
